Kebijakan Privasi Sisa

Terakhir diperbarui: 25 November 2026

Sisa adalah aplikasi pencatat pengeluaran untuk anak kos. Aplikasi ini menghitung jatah harian dari gaji dan tanggal gajian, supaya uangmu cukup sampai gajian berikutnya. Halaman ini menjelaskan data apa yang kami kumpulkan, bagaimana data itu dipakai, dan bagaimana kamu menghapusnya.

Data yang kami kumpulkan

  • Akun. Saat daftar atau masuk, kami menyimpan alamat email dan kata sandi (terenkripsi) melalui layanan autentikasi Supabase. Bila masuk dengan Google, kami menerima nama, alamat email, dan foto profil dari akun Google-mu.
  • Data keuangan di aplikasi. Gaji, tagihan tetap, target tabungan, dan catatan pengeluaran yang kamu isi tersimpan di perangkatmu sendiri (penyimpanan lokal peramban). Data ini tidak dikirim ke server kami.
  • Waitlist. Bila kamu mengisi formulir waitlist di halaman utama, nama, email, dan jawabanmu disimpan di Google Sheets milik pengembang untuk keperluan menghubungi pendaftar.

Bagaimana data dipakai

Data akun dipakai hanya untuk masuk ke aplikasi. Data keuangan dipakai hanya untuk menghitung jatah harian dan menampilkan ringkasan pengeluaranmu. Data waitlist dipakai hanya untuk memberi kabar saat Sisa diluncurkan. Kami tidak menjual datamu dan tidak membagikannya ke pihak lain untuk iklan.

Pihak ketiga

  • Supabase — menyimpan akun dan proses masuk (termasuk login Google).
  • Google — login Google dan penyimpanan data waitlist (Google Sheets).

Menghapus datamu

Kamu bisa menghapus data keuangan di aplikasi kapan saja dengan menghapus data aplikasi di pengaturan perambanmu (local storage). Untuk menghapus akunmu, hubungi kami di alamat di bawah dan kami akan menghapus akun beserta datanya.
